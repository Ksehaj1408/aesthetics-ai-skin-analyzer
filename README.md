# Aesthetics & AI Skin Analyzer

A luxury-themed Streamlit app for facial analysis and skin diagnostics using computer vision and facial landmark detection.

## Features
- Face detection and facial landmark mapping
- Skin texture and tone analysis
- Structural scoring panel
- Recommendation tabs for skincare and lifestyle
- Beautiful dark luxury UI with black-and-gold styling

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud
1. Push this repo to GitHub
2. Go to https://share.streamlit.io/
3. Select this repo and set the app file to `app.py`
4. Deploy

## Deploy on Render
Use the included `render.yaml` or a Dockerfile if you want containerized deployment.
